## 🚀 Cómo Usar Este Repo

1. **Clona** el repositorio
2. **Empieza** por [Guía de Inicio](guides/getting-started.md)
3. **Sigue** el [Roadmap Sugerido](resources/roadmaps.md)
4. **Practica** con los [Proyectos](resources/practice-projects.md)
5. **Consulta** las [Cheatsheets](cheatsheets/) cuando necesites referencia rápida

## 💡 Filosofía

> "La mejor forma de aprender a programar es programando."

- **Práctica > Teoría**: Cada guía tiene ejercicios
- **Proyectos reales**: Aprende construyendo cosas útiles
- **Comunidad**: Comparte tus avances, pregunta, colabora

## 🤝 Contribuir

¿Encontraste un error? ¿Quieres agregar algo? ¡PRs bienvenidos!

1. Fork el repo
2. Crea una rama: `git checkout -b mi-mejora`
3. Commit: `git commit -m "feat: agrega guía de X"`
4. Push: `git push origin mi-mejora`
5. Abre un Pull Request
